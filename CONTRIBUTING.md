# Contributing to openrepo-kit

Thanks for helping improve `openrepo-kit`.

## Local Setup

```bash
npm install
npm test
npm run lint
```

## Pull Requests

- Keep changes focused and easy to review.
- Add or update tests for behavior changes.
- Update README examples when commands, options, or output change.
- Avoid adding runtime dependencies unless the feature clearly needs them.

## Issues

Helpful issues include:

- What you expected to happen.
- What actually happened.
- A small repository layout or command that reproduces the problem.
- Your operating system and Node.js version.
