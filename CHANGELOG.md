# Changelog

All notable changes to this project will be documented in this file.

## 0.4.0

- Added `--output <file>` for audit and badge reports.

## 0.3.1

- Added a stable latest-release tarball link for easier installation.

## 0.3.0

- Added `badges` to suggest README badges from local repository metadata.

- Added Markdown audit reports for pull requests and CI summaries.
- Added `audit --fail-under <score>` for repository health gates.
- Expanded docs, examples, and release packaging.

## 0.1.0

- Initial release with repository audit and starter-file generation.
